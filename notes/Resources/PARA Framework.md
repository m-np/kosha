# PARA Framework

> Developed by Tiago Forte. PARA stands for Projects, Areas, Resources, Archive.

---

## The Four Categories

### Projects
Short-term efforts with a clear goal and deadline.
*Example: [[Second Brain Setup]], Write quarterly report*

### Areas
Long-term responsibilities with no end date.
*Example: Health, Finance, Work, Learning*

### Resources
Topics of ongoing interest that may be useful someday.
*Example: Books, Articles, Tools, Recipes*

### Archive
Inactive items from the other three categories.
*Move completed projects and outdated resources here.*

---

## The Key Insight

Information is actionable. Everything you save should eventually connect back to a **Project** — otherwise, why are you saving it?

Before capturing anything, ask: *"Which project does this serve?"*

---

## How It Works With Kosha

Kosha's sidebar maps directly to PARA. Use [[Second Brain Setup]] for a running log of how this system is evolving.

- Capture → Resources
- Clarify → Projects (is there a task here?)
- Reflect → Areas (does this belong to a long-term responsibility?)
- Engage → Archive (when done)
